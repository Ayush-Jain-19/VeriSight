1. Deep Learning Architecture & Pipeline Flow

Our system processes incoming media through a dual-stream neural hierarchy before merging feature representations in a calibrated late-fusion classification layer.

A. Visual Modality: Cascaded Convolutions & EfficientNet

  • Face Localization via MTCNN: Unconstrained video frames contain non-relevant background pixels (furniture, scenery, ambient illumination). We utilize a 3-stage cascaded convolutional network (Proposal Network P-Net, Refine Network R-Net, and Output Network O-Net) to locate face bounding boxes and normalize facial landmarks.
  • Representation Learning via EfficientNet-B0: Cropped facial crops (224×224) pass into an EfficientNet-B0 architecture using compound scaling. The network learns spatial blending seams, abnormal eye reflection symmetry, mouth boundary warping, and micro-texture smoothing artifacts typical of DeepFaceLab and FaceSwap models.

B. Acoustic Modality: Self-Supervised Speech Representations

  • Wav2Vec 2.0 Transformer Backbone: Rather than converting audio into a static 2D spectrogram image, raw 16 kHz mono waveforms are fed directly into a multi-layer 1D Temporal CNN encoder followed by a Transformer encoder.
  • What It Detects: The self-supervised contextualized latent representations detect phase discontinuities, unnatural formant shifts, vocoder artifacts, and the absence of biological micro-hesitations characteristic of neural TTS and voice cloning (e.g., ElevenLabs, VALL-E).

C. Cross-Modal Fusion: Late-Fusion Multi-Layer Perceptron (MLP)

  • Feature Concatenation: Individual model logits are converted into sigmoid probabilities ($p_v, p_a$) and concatenated with their 128-dimensional latent bottleneck representations: $$\mathbf{z}_{\text{fusion}} = [p_{\text{video}},\, p_{\text{audio}},\, \mathbf{e}_{\text{video}},\, \mathbf{e}_{\text{audio}}] \in \mathbb{R}^{258}$$
  • Cross-Modal Reasoning: The MLP learns whether acoustic cadence synchronizes with visual speech cues, catching sophisticated attacks where an authentic video has had a cloned audio track dubbed onto it.
  • Calibrated Abstention ($\tau$): High-stakes forensic decisions cannot tolerate random guesses. If the predicted confidence does not cross the calibrated validation threshold $\tau_{\text{fusion}}$, the system abstains with an explicit UNCERTAIN verdict.

2. System Engineering: What Was Affected by Introducing Deep Learning?

Choosing deep learning fundamentally changed our application design, requiring deliberate trade-offs across generalization, resource budgets, and defensive software engineering.

1. Generalization Gap
Neural networks overfit to training distributions. A model trained on GANs fails on Diffusion or Flux. We resolved this by building a Hybrid Architecture coupling DL with classical signal forensics (2D FFT, ELA).
2. Latency & Resource Budget
Heavy 3D-CNNs require 16GB VRAM and take 30s. By choosing EfficientNet-B0 and 8-frame uniform temporal sampling, we cut inference time from 25s to 2.8s on CPU, keeping peak RAM under 800MB.
3. Graceful Modality Routing
Real videos often lack speech or human faces. The architecture implements dynamic routing: if faces are absent, it shifts to holistic frame physics; if audio is absent, it routes through visual direct path.

A. Why Deep Learning Alone Was Not Sufficient: The Hybrid Forensics Engine

To make our system resilient against "zero-day" generative tools, we integrated mathematical signal processing alongside deep learning:

  • 2D Fast Fourier Transform (FFT) Spectral Decay: Generative upsampling algorithms (Transposed Convolutions) introduce faint periodic grid lines in frequency space. The 2D FFT radially computes high-frequency energy decay to differentiate organic camera optics from synthetic frequency spikes.
  • Error Level Analysis (ELA): JPEG lossy compression produces uniform error levels across an authentic image. When an AI face is spliced onto an authentic background, the compression rate diverges along the blending boundaries.
  • Statistical Linguistic Analyzer: In text verification, pure LLMs often display overconfidence. We compute mathematical burstiness variance, Shannon n-gram entropy, and Type-Token Ratios (TTR) to detect the statistical uniformity typical of machine generation.

B. Defensive API Engineering & RFC Compliance

Deep learning libraries (PyTorch, OpenCV) assume well-formed numeric arrays. When presented with truncated files, zero-byte uploads, or corrupt headers, native C++ bindings crash with segmentation faults or produce unhandled 500 errors. We built:

  • Defensive Boundary Verification: Upfront file size validation (size == 0) and sanitized decoding wrappers that return clean 400 Bad Request responses instead of bubbling up 500 Internal Server Errors.
  • Information Disclosure Prevention: FFmpeg subprocess errors are sanitized to prevent internal host paths (C:\Users\...) and system binaries from leaking into response payloads.
  • DoS Protection: Input length clamps (50,000 characters) on linguistic endpoints prevent CPU starvation from unbounded sliding-window entropy calculations.

4. Sample Viva / Examination Questions & Model Answers

  1. Q: Why did you choose Late Fusion over Early Fusion?
    A: Early fusion (concatenating raw pixels and audio spectrograms at input) forces rigid synchronization, explodes input dimensionality, and crashes completely if one modality is missing (e.g. silent video). Late fusion allows each specialized model (EfficientNet for vision, Wav2Vec for speech) to extract rich domain features independently before merging probability and embedding vectors, enabling robust modality routing.
  2. Q: What prevents your model from outputting false positives on low-quality web videos?
    A: We implemented calibrated decision thresholds with an abstention policy. If low resolution, poor lighting, or high compression reduces model confidence below $\tau = 0.56$, the system refuses to make an arbitrary guess and returns an honest UNCERTAIN verdict along with diagnostic warnings.
